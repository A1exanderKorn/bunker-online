# Вероятности карт действия

Редактировать `action-card-probabilities.json`. Каталог самих карт — `action-cards.json`.

Каждый массив содержит 7 весов для взвешенного среднего КФ персонажа:

| Индекс | КФ |
|---|---|
| 0 | ≤ 0.25 |
| 1 | > 0.25 и ≤ 0.35 |
| 2 | > 0.35 и ≤ 0.40 |
| 3 | > 0.40 и ≤ 0.45 |
| 4 | > 0.45 и ≤ 0.50 |
| 5 | > 0.50 и ≤ 0.60 |
| 6 | > 0.60 |

Это относительные веса: вероятность категории = её вес / сумму весов непустых категорий в выбранной корзине. При сумме 1 вес 0.25 означает 25%. Веса должны быть конечными и неотрицательными. Не обнуляйте все доступные категории в одной корзине: иначе используется первая непустая категория.

В настройке силы карт `balanced` используется корзина своего КФ, `strong` — на две позиции левее, `weak` — на две правее, с ограничением краями массива. Используется фактический КФ персонажа, не целевой КФ лобби. После категории равновероятно выбирается карта из неё; ограничение уникальности и резервная выдача могут менять итоговое распределение.

Порядок категорий: S → A → B → D → C. Пустая категория не участвует в ролле даже с ненулевыми весами.

На выбор категории делается ровно один `Math.random()` в диапазоне [0, 1). Нормализованные вероятности образуют последовательные интервалы: например, при S = 15% и A = 25% это S [0, 0.15), A [0.15, 0.4), затем остальные. Отдельных бросков по категориям нет. Конкретная карта внутри выбранной категории выбирается отдельным случайным числом.

При стартовой раздаче допускается максимум две карты S и две карты A на лобби. После выдачи второй карты соответствующая категория исключается из последующих бросков, оставшиеся веса нормализуются. Минимум не гарантируется: S и A могут не выпасть вообще, замены после раздачи нет. У каждого игрока одна стартовая карта. Получение копии сыгранной карты и ручная выдача через админку во время матча не являются стартовой раздачей и не ограничиваются этими лимитами.

Пороги КФ и сдвиг силы — `coefBucket` и `bucketWithPower` в `server/cards.ts`. Средний КФ — `averageCoef` там же. Изменения JSON подхватываются после пересборки и перезапуска сервера.
